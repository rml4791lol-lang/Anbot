关于 Anbot：开源、Bot 团队与边界

Anbot 是一个开源、多 Agent 的 Bot 团队，工作在你的真实文件夹。它不是单个聊天窗口：常驻 Bot 可以拆分任务、在群聊里共享上下文，并把结果写回文件。

这页说明产品定位、开源边界、数据位置和联系方式；场景库有 3,000 个页面，具体能力和版本以仓库、Release 和界面为准。

一句话答案：Anbot 把 Bot 当长期角色，把任务放进真实工作区；代码 Apache 2.0，模型由你配置的服务商计费。

这是什么

定位

  • 开源、多 Agent 的 Bot 团队：Main Bot 拆任务，专业 Bot 交付，群聊共享上下文。
  • 工作在真实文件夹：结果落到文件，不只停在聊天里。
  • 可接管：任务有状态、检查点和人工审批；高风险动作不默认放行。

开源边界

代码与模型分开

  • 应用和插件代码采用 Apache 2.0；再分发需保留许可证和版权声明。
  • 模型调用由你配置的服务商计费，不是「代码免费就全部免费」。
  • 第三方组件、商标和连接器分别适用各自条款；商用前请让法务确认。
  • 不内置录音转写；会议流程从已有逐字稿开始。

数据在哪里

数据流

团队工作在你选择的文件夹；数据是否出网，取决于你配置的模型服务商、连接器和工具。不要把「本地工作区」误解成「所有内容都不会离开本机」；敏感数据先脱敏，并逐项确认连接器的数据流。

常见问题

Anbot 是开源软件吗？

应用和插件代码采用 Apache 2.0；模型调用由你配置的服务商计费，第三方组件和商标分别适用各自条款。

Anbot 和数据在哪里？

团队工作在你的真实文件夹；数据出网取决于你配置的模型和连接器，不能一概说本地或云端。
