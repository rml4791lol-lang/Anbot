使用场景

集成

6 篇

把 GitHub、Notion、Linear、Figma、邮箱和 MCP 接进团队。

让 Anbot 接入 GitHub：Issue、PR 和 Actions 日志把仓库、Issue、PR、Actions 日志接进 Bot 的上下文。让 Anbot 接入 Notion：页面与数据库读写读写页面和数据库，把会议、任务和文档接进同一个上下文。让 Anbot 接入 Linear：Issue、项目与周期读 Issue、项目和周期，把任务状态同步到团队上下文。让 Anbot 接入 Figma：读稿与导出切图读设计文件、导出切图，让设计稿进入 Bot 的上下文。让 Anbot 接入邮箱：收件规则与起草回复收发邮件、跑收件规则，外发默认要确认。让 Anbot 接入 MCP：把外部工具变成 Bot 能力把外部工具通过 MCP 接进来，按 Bot 分配能力。

对比

4 篇

和 Grok Bot、大厂 Agent、单 Agent、Claude Code 直接对比。

Anbot vs Grok Bot：常驻 Bot 团队怎么选都做常驻 Bot 团队；差别在托管还是本地、开源还是付费 beta。Anbot vs 大厂 Agent：OpenAI、Claude、Gemini、Copilot大厂 Agent 强在单机执行和产品集成；Anbot 强在开放运行时和多 Bot 团队。Anbot vs 单 Agent 聊天：什么时候需要 Bot 团队单 Agent 聊天适合问答；多 Bot 团队适合能拆分、能验收的活。Anbot vs Claude Code：单机编码 Agent 和 Bot 团队Claude Code 是强单机编码 CLI；接进 Anbot 后多了团队、群聊、接管和审批。

问答

10 篇

关于开源、免费、数据、平台、模型、安全和上手的短答案。

Anbot 是什么？开源多 Agent Bot 团队一句话定义、形态、核心能力和适用人群。Anbot 免费吗？应用开源，模型另计应用和代码免费，模型调用由服务商计费。Anbot 开源吗？Apache 2.0 的边界Apache 2.0，应用/插件代码开放，预设和索引可替换。Anbot 的数据存在哪里？本机优先怎么理解团队、聊天、记忆、凭据和执行记录默认留在本机。Anbot 支持哪些平台？Windows、macOS、Android、LinuxWindows、macOS、Android；Linux 源码；暂无 iOS 安装包。Anbot 用什么模型？模型怎么配置模型由你配置；支持服务商、本地 Agent 和本地模型。Anbot 能离线用吗？哪些部分需要联网界面和数据可以离线，模型推理要看你是云端还是本地。怎么开始用 Anbot？五步跑通第一个 Bot下载安装、配置模型、建 Main Bot，跑一个最小任务。Anbot 安全吗？本地优先与审批边界本地数据、审批、检查点、接管，但不是绝对安全保证。Anbot 能编辑 Office 文件吗？Word、PPT、Exceldocx/pptx/xlsx 的创建、编辑与渲染检查，桌面端能力最全。

  • 先按任务找：会议、代码审查、长任务、内容、Office、浏览器、Issue、守夜、交接。

  • 最后看对比和问答：和 Grok Bot、大厂 Agent、单 Agent、Claude Code 的边界，以及开源、免费、数据、平台、模型、安全。

这 30 篇不是把同一个模板换 30 个标题。每篇都有具体的适合谁、怎么做、验收标准和边界；做不到的地方会直接写出来。

常见问题

这些指南是官方文档吗？

它是 Anbot 的公开使用指南，按真实任务组织；产品能力和限制以仓库、Release 和界面为准。

Anbot 和 Grok Bot 一样吗？

都做常驻 Bot 团队，但 Anbot 走开源、本地工作区和可接管；Grok Bot 更偏托管 beta。具体对比看 vs Grok Bot。

30 篇之后还会增加吗？

会。先看这批页面 7 天内的抓取、索引和引用数据，再按真实问题扩量；不会先堆几百个空模板。
