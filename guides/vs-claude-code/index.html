Anbot vs Claude Code：单机编码 Agent 和 Bot 团队

Claude Code 是很强的单机编码 Agent：它有自己的登录、套餐、模型、工具和上下文。Anbot 不替代它，而是把它接成团队里的一个 Bot，让编码、审查、文档和交接在同一个群聊里发生。

本页是 30 篇指南中的 1 篇，基于 Anbot 0.0.1；下面给出 4 个步骤、4 条验收标准、3 个限制。

一句话答案：一个人写代码、任务边界清楚，Claude Code 单独用更直接；需要多个 Agent 分工、群聊共享上下文、长任务接管和审批，就把 Claude Code 接进 Anbot。

适合谁

  • 已经在用 Claude Code 的开发者
  • 想让编码 Agent 和审查/文档 Bot 协作的人
  • 需要保留 Claude Code 套餐和登录的人

怎么做

  1. 先单独跑通 Claude Code 的一个任务，确认登录、模型和权限都正常。
  2. 在 Anbot 的本地 Agent 设置里接入 Claude Code，指定工作文件夹和权限；给它独立 worktree。
  3. 把它拉进群聊，和 Main Bot、审查 Bot 分工；明确它只负责哪一段、交付什么。
  4. 需要你接手时用接管；Claude Code 自己的工具和上下文不被 Anbot 的连接器替换。

验收标准

  • Claude Code 仍用自己的登录和套餐
  • 任务在独立工作区，主分支不被覆盖
  • 团队交接有明确产物和验收
  • 运行时能确认 CLI 已安装/登录

边界与限制

  • 本地 Agent 不会自动获得 Anbot 的共享连接器
  • 模型/本地 Agent 切换会开新对话分段
  • Claude Code 的能力和计费由 Anthropic 决定

常见问题

Anbot 会替代 Claude Code 吗？

不会。它是把 Claude Code 接进团队协作层；单机编码仍可直接用 Claude Code。

Claude Code 的费用算在 Anbot 吗？

不算。它使用自己的登录和套餐；Anbot 不代收。
