Anbot 支持哪些平台？Windows、macOS、Android、Linux

当前 v0.0.1 提供 Windows 10/11、macOS（Apple 芯片/Intel）和 Android 安装包；Linux 从源码构建，没有官方 Linux 包；没有可安装的 iOS 包。

本页是 30 篇指南中的 1 篇，基于 Anbot 0.0.1；下面给出 4 个步骤、4 条验收标准、3 个限制。

一句话答案：桌面端是主力，Android 用来远程控制，Linux 需要自己构建；插件和 Docker 是另外两种形态。

适合谁

  • 在确认自己机器能不能用的人
  • 要部署到 Linux 服务器的团队
  • 想知道移动端能力的人

怎么做

  1. 桌面端：Windows 下载 .exe，macOS 按芯片下载 .zip；首次安装按发布页说明。
  2. 移动端：安装 Android .apk；通过配对连接你电脑上的团队，不需要公网 IP。
  3. Linux：从源码构建；当前发布页没有 Linux 安装包。
  4. 插件/Docker：按 README 的安装章节配置，适合已有运行时的用户。

验收标准

  • 下载的包和平台/芯片匹配
  • 知道 Android 是远程控制而不是完整桌面端
  • Linux 用户接受源码构建
  • 没有把 iOS 当成当前可用平台

边界与限制

  • 各平台能力不完全一致（如 Office 创建/渲染、浏览器面板）
  • Android 依赖电脑端在线
  • Linux 构建需要 Node/依赖环境

常见问题

有 iOS 版吗？

当前 v0.0.1 没有可安装的 iOS 包；发布说明写明了这个限制。

Android 能单独跑 Bot 吗？

它主要通过加密连接控制你电脑上的团队，不是把完整运行时搬到手机。
