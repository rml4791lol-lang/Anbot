怎么开始用 Anbot？五步跑通第一个 Bot

第一次用不要先建十个 Bot。先装好桌面端、配一个模型、建一个 Main Bot，用一个真实小任务跑通「派活—执行—验收—接管」。

本页是 30 篇指南中的 1 篇，基于 Anbot 0.0.1；下面给出 5 个步骤、4 条验收标准、3 个限制。

一句话答案：下载对应平台安装包 → 配置模型 → 建 Main Bot → 给一个真实任务 → 看 X-Ray 和产物；跑通后再加专业 Bot。

适合谁

  • 第一次安装 Anbot 的人
  • 想先小范围试用的团队
  • 需要给同事写上手步骤的人

怎么做

  1. 从 Release 页下载匹配平台的包；Windows 双击安装，macOS 按芯片选包，Android 装 APK。
  2. 首次启动选择数据目录，配置模型服务商/API key；先测试一个最小请求。
  3. 建一个 Main Bot，写清角色、工作文件夹和权限；不要一上来给全盘/无审批。
  4. 给它一个 30 分钟内能完成的任务：读一个文件、写一份摘要、改一个副本；检查产物和 X-Ray。
  5. 跑通后再加一个专业 Bot 或群聊；需要长任务时先设检查点。

验收标准

  • 安装包与平台匹配
  • 模型请求能跑通
  • Main Bot 有工作文件夹和权限边界
  • 第一个任务有可验收产物

边界与限制

  • 首次配置需要模型服务商/API key
  • 不同平台安装步骤不同
  • 复杂任务先拆小，不要用第一个任务压测

常见问题

需要先装别的运行时吗？

不需要。桌面端自带运行环境；插件形态才需要已有运行时。

第一个任务做什么？

选一个读本地文件并产出摘要/副本的任务，容易验收，也不容易破坏数据。
