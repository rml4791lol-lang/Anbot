Anbot vs 单 Agent 聊天：什么时候需要 Bot 团队

ChatGPT、Claude 这类单 Agent 聊天很适合问答、起草和一次性任务。Anbot 不是把同一个聊天窗口换个皮：它把活拆给多个常驻 Bot，让它们在群聊、任务板和真实工作区里交接。

本页是 30 篇指南中的 1 篇，基于 Anbot 0.0.1；下面给出 4 个步骤、4 条验收标准、3 个限制。

一句话答案：一次性问答用单 Agent 更轻；需要多角色并行、长任务、文件交付和接管时，用 Anbot 的 Bot 团队。不要为了「多 Agent」而多 Agent。

适合谁

  • 在犹豫要不要上多 Agent 的人
  • 任务经常卡在交接和验收的团队
  • 需要把产物落到文件的人

怎么做

  1. 先判断任务能否拆分：有没有明确的角色、并行段和验收标准。
  2. 如果只是一次问答/单文件修改，先用单 Agent；如果要做 3 个以上步骤、多人交接，再上团队。
  3. 用 Anbot 建 Main Bot + 1 个专业 Bot 做最小团队，跑一个真实任务；不要一开始建十个。
  4. 对比返工率、交接时间和可验收性，而不是只看首轮速度。

验收标准

  • 团队规模对应真实角色，不堆 Bot
  • 每个 Bot 有明确交付和验收
  • 任务产物在文件里，不只在聊天里
  • 返工/交接时间有改善

边界与限制

  • 多 Bot 会增加配置、模型调用和协调成本
  • 简单任务用团队反而更慢
  • 单 Agent 的产品体验通常更成熟

常见问题

一个 Bot 不够吗？

很多任务一个 Bot 就够。需要并行、角色分工或独立验收时，再拆团队。

Bot 越多越好吗？

不是。每个 Bot 都要有清晰职责和产物，否则只是多开几个窗口。
