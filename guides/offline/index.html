Anbot 能离线用吗？哪些部分需要联网

Anbot 的界面、团队数据、文件和工作区在本机，断网时仍能打开和整理；但模型推理、远程 MCP、网页浏览和在线连接器需要网络。

一句话答案：能不能完全离线，取决于你把模型放在哪里：用云端 API 就需要网；用本地模型/本地 Agent 且不访问外部工具，才可以接近离线。

适合谁

  • 网络不稳定的人
  • 要在内网/离线环境部署的团队
  • 关心云端依赖的人

怎么做

  1. 先分任务：哪些只需要读本地文件，哪些必须调模型/外部服务。
  2. 需要离线时，配置本地模型或本地 Agent，并关闭不需要的远程 MCP/连接器。
  3. 网页浏览、邮件、GitHub 等在线工具在断网时不可用；给任务加降级路径。
  4. 离线任务的产物仍落本地，恢复网络后再同步/发布。

验收标准

  • 知道哪些步骤依赖网络
  • 本地模型/Agent 已提前下载/登录
  • 断网时任务能停在可恢复的位置
  • 没有把「本地数据」误读成「完全离线」

边界与限制

  • 云端模型 API 必须有网
  • 远程 MCP/OAuth 需要网络
  • 本地模型能力通常小于前沿云端模型

常见问题

断网还能聊天吗？

界面和本地数据能打开；如果模型在云端，生成会失败。

能完全本地部署吗？

可以接近，但需要本地模型、本地工具和离线依赖；具体能力取决于你的配置。
