让 Anbot 接入 Figma：读稿与导出切图

设计稿常在 Figma 里，开发却要切图、量间距、对颜色。接入后，Bot 可以读文件结构、导出指定切图，把设计信息带进实现任务；它不应该替设计师改稿。

一句话答案：授权 Figma 文件，先让 Bot 读页面/图层/样式；需要切图时指定节点和尺寸；导出后检查文件名、倍率和边界。

适合谁

  • 要把设计稿转成实现任务的前端
  • 需要批量导出切图的人
  • 想让 Bot 检查设计一致性的团队

怎么做

  1. 授权目标 Figma 文件；先让 Bot 列出页面、组件和样式 token，确认文件结构。
  2. 指定要导出的节点、格式、倍率和命名规则；先导 1–2 个验证，再批量。
  3. 让 Bot 把颜色、字号、间距、圆角等 token 整理成表，和代码里的变量对照。
  4. 导出文件落到工作区；设计变更仍由设计师确认，Bot 不直接改源文件。

验收标准

  • 切图文件名、格式、倍率符合约定
  • 导出的边界没有裁切/留白
  • 设计 token 和代码变量能对上
  • 源文件没有被 Bot 修改

边界与限制

  • Figma API 权限和文件结构会影响读取
  • 复杂组件/变量可能无法完整导出
  • 设计意图仍要设计师确认

常见问题

能替设计师改稿吗？

不建议。这个流程以读取和导出为主，改稿由设计师做。

支持批量切图吗？

可以，先小批验证命名和边界，再扩大。
