让 Anbot 接入 Linear：Issue、项目与周期

Linear 里的 Issue 和项目状态，是团队判断「现在该做什么」的依据。接入后，Bot 可以汇总阻塞项、把会议待办建成 Issue，也可以按周期检查进度。

本页是 30 篇指南中的 1 篇，基于 Anbot 0.0.1；下面给出 4 个步骤、4 条验收标准、3 个限制。

一句话答案：用 OAuth 连接 Linear，指定团队和项目；先只读汇总，再让 Bot 起草 Issue；创建/改状态前确认字段和负责人。

适合谁

  • 用 Linear 管研发任务的团队
  • 要把会议待办转成 Issue 的人
  • 需要每周看阻塞项的项目负责人

怎么做

  1. 授权 Linear，选择团队/项目；让 Bot 读一次当前周期、打开 Issue、阻塞项和负责人。
  2. 让 Bot 输出一页简报：本周目标、已完成、阻塞、无人负责的事项；每条带 Issue 链接。
  3. 需要建 Issue 时，先给标题、描述、优先级、负责人和项目；你确认后再创建。
  4. 状态变更和关闭要单独确认；不要让 Bot 批量改状态。

验收标准

  • 简报能回到具体 Issue
  • 新建 Issue 字段完整、负责人明确
  • 没有批量改状态/关闭
  • 阻塞项有下一步和 owner

边界与限制

  • 依赖 Linear 团队/项目权限
  • 跨项目汇总可能受 API 分页限制
  • 优先级仍由人决定

常见问题

能自动把邮件变成 Issue 吗？

可以让 Bot 读邮件后起草 Issue，但创建前要你确认。

支持多个团队吗？

可以按团队分别授权和查询，避免把不同团队的数据混在一起。
