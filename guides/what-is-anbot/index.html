Anbot 是什么？开源多 Agent Bot 团队

Anbot 是一个开源的多 Agent 工作台：一支持久在线的 Bot 团队，在你的真实工作区里干活。主 Bot 拆任务，专业 Bot 接活，群聊共享记忆、上下文和任务板。

本页是 30 篇指南中的 1 篇，基于 Anbot 0.0.1；下面给出 3 个步骤、3 条验收标准、3 个限制。

一句话答案：它不是单个聊天窗口，也不是一个云端 Agent 服务；它把多个常驻 Bot、真实文件夹、任务板、检查点和接管组合成一个本地优先的工作台。

适合谁

  • 第一次了解 Anbot 的人
  • 在选多 Agent 工作台的人
  • 关心开源和本地数据的人

怎么做

  1. 先看形态：Windows/macOS 桌面端、Android 客户端、插件、Docker；Linux 从源码构建。
  2. 再看能力：Main Bot + 专业 Bot、群聊共享上下文、X-Ray、检查点、接管、审批、本地 Agent 接入。
  3. 最后看边界：模型要自己配置，复杂任务仍需人验收，不是全自动替代人。

验收标准

  • 能用自己的话解释「多 Bot 团队」和「单 Agent」的区别
  • 知道数据默认在本机、模型请求发给服务商
  • 知道它不是免费模型，应用开源但模型另计

边界与限制

  • 不是开箱即用的云服务，需要本机安装和模型配置
  • 不同平台能力有差异，创建/渲染 Office 文件需要桌面端
  • 多 Agent 不是所有任务都更快

常见问题

Anbot 是开源的吗？

是，Apache 2.0。应用和插件代码开源，预设、技能和索引可读可换。

Anbot 有免费模型吗？

没有内置免费模型；你配置自己的模型服务商，费用由服务商计。
