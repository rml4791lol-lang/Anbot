Anbot 用什么模型？模型怎么配置

Anbot 不自带模型。每个 Bot 可以选择你配置的服务商模型、本地 Agent，或本地模型；团队可以混用不同模型。

本页是 30 篇指南中的 1 篇，基于 Anbot 0.0.1；下面给出 4 个步骤、4 条验收标准、3 个限制。

一句话答案：在设置里配置模型服务商/API key，再给每个 Bot 选模型；本地 Agent 用它自己的登录和套餐。模型费用由对应服务商/CLI 计。

适合谁

  • 要接自己的 API key 的人
  • 想混用不同模型/本地 Agent 的团队
  • 关心模型锁定的人

怎么做

  1. 在设置里添加模型服务商，填 API key/base URL（如需要），先测试一个最小请求。
  2. 给 Main Bot 选一个稳定的模型；专业 Bot 可按任务选更便宜/更强的模型。
  3. 需要本地 Agent 时，先在终端安装/登录 CLI，再在 Anbot 里选择它。
  4. 用运行时探针确认当前 Bot 实际用的模型/路由；不要假设全局设置等于每个 Bot。

验收标准

  • 每个 Bot 的模型可查
  • API key 在 Secrets/设置里，不在指令里
  • 本地 Agent 的登录/套餐独立
  • 成本和配额有预算

边界与限制

  • 模型能力/价格由服务商决定
  • 切换模型可能开启新的对话分段
  • 本地模型需要硬件和推理服务

常见问题

能用一个 key 给所有 Bot 吗？

可以，但不同 Bot 的模型/配额可能不同；按任务分配更可控。

支持 OpenAI 兼容接口吗？

支持兼容适配；具体 base URL 和模型名以你的服务商为准。
