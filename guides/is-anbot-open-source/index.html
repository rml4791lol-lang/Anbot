Anbot 开源吗？Apache 2.0 的边界

Anbot 的应用和插件代码以 Apache 2.0 开源；预设、技能、MCP 和插件索引也是可读、可替换的。它不是「源码可见但扩展面锁死」的假开源。

本页是 30 篇指南中的 1 篇，基于 Anbot 0.0.1；下面给出 4 个步骤、3 条验收标准、3 个限制。

一句话答案：你可以查看、修改、分发代码，也可以替换预设和索引；但要保留许可证声明，模型和第三方连接器仍受各自条款约束。

适合谁

  • 要审计代码的团队
  • 想改界面/预设的开发者
  • 关心 vendor lock-in 的人

怎么做

  1. 看仓库的 LICENSE 和 NOTICE，确认 Apache 2.0 的义务。
  2. 看应用、插件和桌面端各自的目录，确认你要改的部分；改之前先确认哪一层归你维护。
  3. 预设/技能/索引是数据文件；改之前先备份，避免升级覆盖。
  4. 商用/再分发时保留版权和许可证声明，第三方素材单独确认。

验收标准

  • 能指出代码、预设、索引各自的许可证
  • 知道 Apache 2.0 的义务
  • 没有把第三方模型/连接器当成 Anbot 开源的一部分

边界与限制

  • Apache 2.0 不提供 warranty
  • 第三方模型、字体、图标、连接器有各自许可
  • 开源不等于有人义务支持你的定制

常见问题

能闭源分发吗？

可以在遵守 Apache 2.0 的前提下分发；保留声明，修改文件要标注。

能改品牌吗？

代码许可允许修改，但商标/品牌使用要看项目政策；不要把修改版冒充官方。
