# Anbot issue tracker

Track Anbot issues and pull requests in `rml4791lol-lang/Anbot`. Use `gh --repo rml4791lol-lang/Anbot` where the command supports it, so the workspace's historical remotes cannot route write operations to the wrong repository.

`rml4791lol-lang/DS-Bot` is the previous fork. Its issue and PR numbers refer to that repository. `Fei2411/DS-Bot` is the historical upstream source. Cite the full repository when referencing either history.

The [triage skill](../../.agents/skills/issue-triage/SKILL.md) and [labels](triage-labels.md) describe the issue workflow. Pull requests are not a feature-request channel.
