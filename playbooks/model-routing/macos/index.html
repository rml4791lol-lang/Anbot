Anbot · 给不同 Bot 配不同模型｜macOS版

模型路由不是省钱技巧；要让任务需求和模型能力匹配。 macOS 上先确认文件和权限；不要假设云端一定有副本。

本页是 3,000 个场景页中的 1 个，基于 Anbot 0.0.1；下面给出 5 个步骤、5 条验收标准、4 个限制。

一句话答案：先按任务分层，再给每层配模型和预算，最后用真实任务测质量/成本。 在macOS下，先先确认工作区路径、磁盘权限和 Apple 芯片/Intel 包，再按验收表逐项确认。

适合谁

  • 要控制模型成本的人
  • 多 Bot 团队
  • 对延迟/数据敏感的组织
  • 在 Mac 上运行的团队

怎么做

  1. 把任务按难度、上下文、工具和敏感度分层。
  2. 给每层配候选模型和预算；高风险任务保留强模型。
  3. 用同一批任务测质量、延迟和成本；按结果调整。
  4. 安装包按芯片选；首次运行按发布页说明放行。
  5. 文件操作只用本地路径；导出前检查换行和编码。

验收标准

  • 每层有选择理由
  • 成本/质量有数据
  • 敏感任务不降级
  • 可回退
  • 安装包与芯片匹配，任务能在本机复跑

边界与限制

  • 模型能力/价格会变
  • 路由增加配置复杂度
  • 不能只看单价
  • 部分 Windows 专属工具/Office 能力可能不同

常见问题

便宜模型能替代吗？

看任务；高风险/长上下文不要盲降。

能自动路由吗？

可以按规则；先人工定层。

Apple 芯片和 Intel 用同一个包吗？

不；发布页有 arm64 和 x64 两个包。
