Anbot · 算清 Anbot 的使用成本｜Linux版

免费应用不等于零成本；模型调用和运维才是变量。 Linux 多用于构建和服务；先准备依赖，再谈桌面能力。

本页是 3,000 个场景页中的 1 个，基于 Anbot 0.0.1；下面给出 5 个步骤、5 条验收标准、4 个限制。

一句话答案：先列固定/变动成本，再按任务量估算模型费用，最后算迁移和退出成本。 在Linux下，先先确认 Node/依赖、权限和是否需要图形界面，再按验收表逐项确认。

适合谁

  • 要申请预算的人
  • 比较自建和采购的团队
  • 给客户报价的服务商
  • 在 Linux 服务器/桌面运行的团队

怎么做

  1. 列应用、模型、托管、运维、培训和迁移成本。
  2. 按任务量/ token/重试估算变动成本，给区间。
  3. 做 3 种用量情景；标出最敏感变量。
  4. 从源码构建，记录版本和依赖；不要混用系统 Node。
  5. 无图形界面的环境只跑能无头执行的任务，桌面能力另行确认。

验收标准

  • 成本项完整
  • 假设可解释
  • 有区间而非单点
  • 退出成本写清
  • 构建可复现，任务在目标环境跑通

边界与限制

  • 模型价格会变
  • 用量估算有误差
  • 不能替代财务测算
  • 官方没有 Linux 安装包，桌面能力不保证

常见问题

Anbot 本身收费吗？

应用代码免费；模型和基础设施按你的配置计费。

比 SaaS 便宜吗？

取决于用量和运维；不要只比订阅价。

有 Linux 安装包吗？

当前发布页没有；需要从源码构建。
