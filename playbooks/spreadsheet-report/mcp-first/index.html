Anbot · 把明细表做成月度报表｜MCP 优先版

报表不是把数字变大；先把口径、时间范围和异常定义写清楚。 MCP 优先时先接只读工具，按 Bot 分配权限，高风险工具默认关闭。

本页是 3,000 个场景页中的 1 个，基于 Anbot 0.0.1；下面给出 5 个步骤、5 条验收标准、4 个限制。

一句话答案：先确认口径和维度，再生成汇总与异常清单，最后人工核对总数。 在MCP 优先下，先先接一个只读 MCP，列出工具清单，再按验收表逐项确认。

适合谁

  • 要做月报的人
  • 需要给管理层看数的人
  • 经常被口径问题追问的人
  • 用 MCP 接内部工具的团队

怎么做

  1. 确认统计口径、时间范围、币种和维度；写成表头说明。
  2. 生成汇总表、同比环比和异常项，异常要能回到原始行。
  3. 抽查总数和关键行；把公式和假设留在文件里。
  4. 工具按需加载，不要全部 Always。
  5. 运行时探针确认实际加载和权限。

验收标准

  • 口径写在报表里
  • 总数能对上明细
  • 异常项可追溯
  • 公式没有硬编码月份
  • 工具清单可见，权限按 Bot 分配，高风险默认关闭

边界与限制

  • 源数据质量决定结果
  • 口径变更要重跑
  • 不能替代财务审计
  • MCP 服务器质量和限流由提供方决定

常见问题

能直接发领导吗？

建议先人工核对；报表要带口径和异常说明。

能做图吗？

可以生成图表草稿，但先定图表要回答的问题。

能接本地 MCP 吗？

可以，通过本地网关；具体端口看文档。
