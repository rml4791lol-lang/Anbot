Anbot · 验证一条网上说法的来源｜Windows版

一条说法被转了几手，往往已经不是原意；先找最早出处。 Windows 上先测路径、换行和 Office 兼容，再放量。

本页是 3,000 个场景页中的 1 个，基于 Anbot 0.0.1；下面给出 5 个步骤、5 条验收标准、4 个限制。

一句话答案：先反向搜原句和图片，再找原始页面，最后核对上下文和日期。 在Windows下，先先确认安装包、路径分隔符和 Office 版本，再按验收表逐项确认。

适合谁

  • 要转发前核实的人
  • 写内容需要引用的人
  • 被谣言困扰的团队
  • 在 Windows 上运行的团队

怎么做

  1. 提取原句/图片，做反向搜索和域名限定搜索。
  2. 找最早发布的原始页面，记录作者、日期和上下文。
  3. 对比转述与原文，标出断章/改写/无法确认。
  4. 用 Windows 安装包；路径尽量用绝对路径并加引号。
  5. 批量脚本先在样本目录跑；确认编码和换行一致。

验收标准

  • 能找到原始出处或明确找不到
  • 日期和上下文完整
  • 转述差异有对比
  • 不确定结论不硬下
  • 路径/编码/Office 兼容通过样本测试

边界与限制

  • 删除内容可能只存在缓存
  • 图片可能被二次编辑
  • 闭环证据需要专业工具
  • 不同 Windows 版本的权限和字体有差异

常见问题

能判断真假吗？

能判断来源和上下文；真假结论要看证据强度。

能查视频吗？

可以查关键帧和发布时间，但不能仅凭画面断定。

Windows 10 能用吗？

发布页写明 Windows 10/11 64 位；以实际安装结果为准。
