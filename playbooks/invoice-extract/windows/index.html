Anbot · 从发票 PDF 提取结构化字段｜Windows版

发票提取的难点不是识别文字，而是字段对齐和金额校验。 Windows 上先测路径、换行和 Office 兼容，再放量。

本页是 3,000 个场景页中的 1 个，基于 Anbot 0.0.1；下面给出 5 个步骤、5 条验收标准、4 个限制。

一句话答案：先定义字段和校验规则，再逐张提取，最后用总额/税额/明细做交叉校验。 在Windows下，先先确认安装包、路径分隔符和 Office 版本，再按验收表逐项确认。

适合谁

  • 要录发票的人
  • 做报销/对账的人
  • 需要批量处理 PDF 的团队
  • 在 Windows 上运行的团队

怎么做

  1. 定义字段：发票号、日期、买卖方、金额、税额、明细。
  2. 逐张提取并保留页码/坐标；看不清的字段标「待人工」。
  3. 校验总额=明细合计、税额计算和重复发票；输出 CSV 与异常清单。
  4. 用 Windows 安装包；路径尽量用绝对路径并加引号。
  5. 批量脚本先在样本目录跑；确认编码和换行一致。

验收标准

  • 字段有空值处理规则
  • 金额校验能对上
  • 重复发票有标记
  • 原始 PDF 未被修改
  • 路径/编码/Office 兼容通过样本测试

边界与限制

  • 扫描质量差会影响识别
  • 不同票种模板差异大
  • 不能替代财务合规审核
  • 不同 Windows 版本的权限和字体有差异

常见问题

能开票吗？

不能；只做提取和校验。

能批量跑吗？

可以，但要分批并保留失败清单。

Windows 10 能用吗？

发布页写明 Windows 10/11 64 位；以实际安装结果为准。
