Anbot · 确认 Anbot 的开源边界｜纯本地数据版

开源不等于所有东西都免费；代码、模型、服务和商标要分开看。 纯本地场景先确认模型和工具都不外传，再谈能力。

本页是 3,000 个场景页中的 1 个，基于 Anbot 0.0.1；下面给出 5 个步骤、5 条验收标准、4 个限制。

一句话答案：先看 LICENSE 和 NOTICE，再确认模型由服务商计费，最后区分商标/第三方组件。 在纯本地数据下，先先列数据流，关掉会外传内容的连接器，再按验收表逐项确认。

适合谁

  • 要商用 Anbot 的团队
  • 需要给客户解释许可证的人
  • 准备二次开发的开发者
  • 数据不能出本机的团队

怎么做

  1. 读仓库 LICENSE/NOTICE，确认 Apache 2.0 义务。
  2. 列出模型服务商、第三方组件和商标，分别确认条款。
  3. 把「代码免费/模型计费/服务自理」写进采购/交付说明。
  4. 模型、检索、日志都留在本机；逐项确认没有外部请求。
  5. 敏感文件先脱敏；本地模型能力不足时明确降级范围。

验收标准

  • 许可证类型明确
  • 第三方组件有清单
  • 模型费用说明清楚
  • 没有把开源当成无条件
  • 数据流图显示没有外部传输，日志本地保存

边界与限制

  • 许可证解释需法务确认
  • 第三方组件可能变更
  • 商标使用需授权
  • 本地模型能力和更新速度有限

常见问题

能商用吗？

Apache 2.0 通常允许，但仍需履行许可证义务；以法务为准。

模型也免费吗？

不；模型调用由你配置的服务商计费。

能完全离线吗？

取决于模型和工具；先确认哪些步骤需要联网。
