Anbot · 确认 Anbot 的开源边界｜5–10 人团队版

开源不等于所有东西都免费；代码、模型、服务和商标要分开看。 团队开始有交接成本；先把任务板和共享事实统一，再谈自动化。

本页是 3,000 个场景页中的 1 个，基于 Anbot 0.0.1；下面给出 5 个步骤、5 条验收标准、4 个限制。

一句话答案：先看 LICENSE 和 NOTICE，再确认模型由服务商计费，最后区分商标/第三方组件。 在5–10 人团队下，先先建一个共享任务板和一个只读事实区，再按验收表逐项确认。

适合谁

  • 要商用 Anbot 的团队
  • 需要给客户解释许可证的人
  • 准备二次开发的开发者
  • 五到十人的项目团队

怎么做

  1. 读仓库 LICENSE/NOTICE，确认 Apache 2.0 义务。
  2. 列出模型服务商、第三方组件和商标，分别确认条款。
  3. 把「代码免费/模型计费/服务自理」写进采购/交付说明。
  4. 按角色建 Bot，不按人建；每个人知道哪个 Bot 给自己交付什么。
  5. 每周清理一次 Bot 的失败任务和过期指令，避免越跑越乱。

验收标准

  • 许可证类型明确
  • 第三方组件有清单
  • 模型费用说明清楚
  • 没有把开源当成无条件
  • 交接不靠私聊，能从任务板和文件恢复

边界与限制

  • 许可证解释需法务确认
  • 第三方组件可能变更
  • 商标使用需授权
  • 角色多后协调成本上升，不是 Bot 越多越快

常见问题

能商用吗？

Apache 2.0 通常允许，但仍需履行许可证义务；以法务为准。

模型也免费吗？

不；模型调用由你配置的服务商计费。

需要几个专业 Bot？

先 2–3 个高频角色；低频任务用同一个 Bot 切换。
