Anbot · 把资料包做成 PPT 大纲｜Linear 优先版

PPT 最难的是每页只讲一件事；先定结论，再定页面。 Linear 优先时状态只写一处；Bot 只做草稿/评论。

本页是 3,000 个场景页中的 1 个，基于 Anbot 0.0.1；下面给出 5 个步骤、5 条验收标准、4 个限制。

一句话答案：先写每页一句话结论，再排章节和证据，最后在桌面端生成可编辑草稿。 在Linear 优先下，先先接一个项目只读，再生成分诊/验收草稿，再按验收表逐项确认。

适合谁

  • 要做汇报的人
  • 需要给团队改 PPT 的人
  • 手里有资料但没有结构的人
  • 以 Linear 为任务真源的团队

怎么做

  1. 把资料压缩成 5–7 个结论，每个结论配一条证据。
  2. 按「问题—证据—方案—行动」排页面，每页只放一个结论。
  3. 在桌面端生成 PPTX 草稿；人工检查字体、图表和溢出。
  4. Issue 状态以 Linear 为准；外部表只读。
  5. 状态变更走审批；冲突回 Linear 处理。

验收标准

  • 每页有一句结论
  • 证据能支撑结论
  • 页数与汇报时长匹配
  • 生成后能在 PowerPoint 里编辑
  • 没有双写，状态变更可追溯

边界与限制

  • 复杂动画和品牌模板需要人工处理
  • 图表数据要单独核对
  • 移动端不适合做精细排版
  • 工作流状态因团队而异，不能硬编码

常见问题

能直接生成 PPTX 吗？

可以生成可编辑草稿；最终排版建议在桌面端检查。

能做动态动画吗？

可以另开动画任务；先定内容结构。

能自动关闭 Issue 吗？

先写关闭建议，由人确认。
