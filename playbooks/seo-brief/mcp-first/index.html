Anbot · 为一个关键词写内容简报｜MCP 优先版

SEO 简报不是关键词堆叠；先判断搜索意图，再决定文章该回答什么。 MCP 优先时先接只读工具，按 Bot 分配权限，高风险工具默认关闭。

本页是 3,000 个场景页中的 1 个，基于 Anbot 0.0.1；下面给出 5 个步骤、5 条验收标准、4 个限制。

一句话答案：先分信息型/比较型/交易型意图，再列竞品覆盖和缺口，最后给结构和证据要求。 在MCP 优先下，先先接一个只读 MCP，列出工具清单，再按验收表逐项确认。

适合谁

  • 内容编辑
  • 要给写手派题的人
  • 做独立站内容的人
  • 用 MCP 接内部工具的团队

怎么做

  1. 确认关键词、地区、语言和目标读者；判断意图类型。
  2. 收集前 5 个结果的结构和覆盖点，标出重复和缺口。
  3. 生成简报：标题方向、章节、必须回答的问题、证据和不要写的空话。
  4. 工具按需加载，不要全部 Always。
  5. 运行时探针确认实际加载和权限。

验收标准

  • 简报对应真实搜索意图
  • 竞品覆盖有链接和日期
  • 内容缺口具体
  • 没有承诺排名
  • 工具清单可见，权限按 Bot 分配，高风险默认关闭

边界与限制

  • 搜索结果是动态的
  • 不能替代关键词工具数据
  • 排名和流量不可保证
  • MCP 服务器质量和限流由提供方决定

常见问题

能保证上首页吗？

不能；只能提高内容与意图的匹配度。

能直接写成稿吗？

可以，但建议先确认简报。

能接本地 MCP 吗？

可以，通过本地网关；具体端口看文档。
