Anbot · 什么时候用单 Agent 更合适｜5–10 人团队版

单 Agent 不是落后；简单任务用它更快、更便宜。 团队开始有交接成本；先把任务板和共享事实统一，再谈自动化。

本页是 3,000 个场景页中的 1 个，基于 Anbot 0.0.1；下面给出 5 个步骤、5 条验收标准、4 个限制。

一句话答案：先看任务是否需要多角色/交接；不需要就用单 Agent，需要再升级。 在5–10 人团队下，先先建一个共享任务板和一个只读事实区，再按验收表逐项确认。

适合谁

  • 被多 Agent 方案绕晕的人
  • 做一次性任务的人
  • 要控制成本的团队
  • 五到十人的项目团队

怎么做

  1. 判断任务是否一次性、单文件、无需多人验收。
  2. 用单 Agent 跑一遍，记录返工和交接成本。
  3. 只有出现明确角色/并行/交接需求时才升级团队。
  4. 按角色建 Bot，不按人建；每个人知道哪个 Bot 给自己交付什么。
  5. 每周清理一次 Bot 的失败任务和过期指令，避免越跑越乱。

验收标准

  • 任务真的不需要多角色
  • 成本更低
  • 返工可接受
  • 升级路径清楚
  • 交接不靠私聊，能从任务板和文件恢复

边界与限制

  • 单 Agent 上下文有限
  • 复杂任务容易漏项
  • 不能替代团队协作
  • 角色多后协调成本上升，不是 Bot 越多越快

常见问题

单 Agent 能接工具吗？

可以；工具接入不等于多 Agent。

什么时候升级？

出现独立子任务和交接需求时。

需要几个专业 Bot？

先 2–3 个高频角色；低频任务用同一个 Bot 切换。
