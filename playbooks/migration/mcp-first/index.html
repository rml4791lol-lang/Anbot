Anbot · 从现有工具迁移到 Anbot｜MCP 优先版

迁移不是把文件复制过来；要保留结构、权限和可回退。 MCP 优先时先接只读工具，按 Bot 分配权限，高风险工具默认关闭。

本页是 3,000 个场景页中的 1 个，基于 Anbot 0.0.1；下面给出 5 个步骤、5 条验收标准、4 个限制。

一句话答案：先盘点并备份，再按资料/任务/自动化三阶段迁，最后验证和回退。 在MCP 优先下，先先接一个只读 MCP，列出工具清单，再按验收表逐项确认。

适合谁

  • 要从其他 Agent 迁移的人
  • 换工作流的管理者
  • 需要保留历史记录的组织
  • 用 MCP 接内部工具的团队

怎么做

  1. 盘点现有文件、任务、权限和自动化，做完整备份。
  2. 先迁只读资料，再迁任务，最后迁自动化；每阶段验收。
  3. 保留旧系统只读一段时间；写回退步骤。
  4. 工具按需加载，不要全部 Always。
  5. 运行时探针确认实际加载和权限。

验收标准

  • 原数据有备份
  • 分阶段验收
  • 权限映射清楚
  • 有回退路径
  • 工具清单可见，权限按 Bot 分配，高风险默认关闭

边界与限制

  • 格式/权限可能不兼容
  • 历史上下文难迁移
  • 迁移期双系统成本
  • MCP 服务器质量和限流由提供方决定

常见问题

能一键迁移吗？

不假设；分阶段更安全。

旧数据要删吗？

验证后再按政策归档/删除。

能接本地 MCP 吗？

可以，通过本地网关；具体端口看文档。
