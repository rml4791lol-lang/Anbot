Anbot · 从 PDF 提取关键字段｜Windows版

PDF 提取要能回到原文；只给一段总结，没法审。 Windows 上先测路径、换行和 Office 兼容，再放量。

本页是 3,000 个场景页中的 1 个，基于 Anbot 0.0.1；下面给出 5 个步骤、5 条验收标准、4 个限制。

一句话答案：先定义字段和页码规则，再逐页提取，最后人工抽查表格和数字。 在Windows下，先先确认安装包、路径分隔符和 Office 版本，再按验收表逐项确认。

适合谁

  • 要读长 PDF 的人
  • 做合同/发票录入的人
  • 需要把 PDF 转成表格的人
  • 在 Windows 上运行的团队

怎么做

  1. 确认 PDF 是文本版还是扫描版；扫描版先 OCR。
  2. 按字段提取并记录页码/段落；表格单独导出。
  3. 抽查金额、日期和否定句；把不确定字段标出来。
  4. 用 Windows 安装包；路径尽量用绝对路径并加引号。
  5. 批量脚本先在样本目录跑；确认编码和换行一致。

验收标准

  • 字段能定位到页码
  • 表格数字与原文一致
  • 扫描件有 OCR 质量说明
  • 不确定项没有硬填
  • 路径/编码/Office 兼容通过样本测试

边界与限制

  • 扫描质量差会误识别
  • 复杂跨页表格需要人工处理
  • 不能替代法律审阅
  • 不同 Windows 版本的权限和字体有差异

常见问题

能处理加密 PDF 吗？

需要你提供密码；不要把密码写进公开文件。

能直接总结吗？

可以，但先提取关键字段更稳。

Windows 10 能用吗？

发布页写明 Windows 10/11 64 位；以实际安装结果为准。
