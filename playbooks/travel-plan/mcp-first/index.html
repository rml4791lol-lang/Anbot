Anbot · 做一份可执行的出差计划｜MCP 优先版

行程要能执行；先锁时间和地点，再排交通和缓冲。 MCP 优先时先接只读工具，按 Bot 分配权限，高风险工具默认关闭。

本页是 3,000 个场景页中的 1 个，基于 Anbot 0.0.1；下面给出 5 个步骤、5 条验收标准、4 个限制。

一句话答案：先确认日期/地点/预算，再排主行程和备选，最后核对开放时间和交通。 在MCP 优先下，先先接一个只读 MCP，列出工具清单，再按验收表逐项确认。

适合谁

  • 要安排出差的人
  • 需要给团队做行程的人
  • 经常遇到临时变动的人
  • 用 MCP 接内部工具的团队

怎么做

  1. 确认出发/返回、会议地点、预算和不可变时间。
  2. 按地理位置排每日行程，留交通和缓冲；给至少一个备选。
  3. 核对场馆开放时间、交通耗时和预订要求；标出待确认项。
  4. 工具按需加载，不要全部 Always。
  5. 运行时探针确认实际加载和权限。

验收标准

  • 时间地点能对上
  • 交通有缓冲
  • 预算有明细
  • 关键信息有来源或待确认标记
  • 工具清单可见，权限按 Bot 分配，高风险默认关闭

边界与限制

  • 实时交通/票价会变
  • 签证和差旅政策需人工确认
  • 不能替你做预订
  • MCP 服务器质量和限流由提供方决定

常见问题

能直接订票吗？

不能；可以给链接和备选。

能按预算压缩吗？

可以，标出会牺牲的便利性。

能接本地 MCP 吗？

可以，通过本地网关；具体端口看文档。
