三步装进本机

从索引到你的 Anbot

  1. 1添加索引源

    一条命令接上目录，之后它出现在 Anbot 的「发现」页。

    anbot market add <索引地址>

  2. 2挑条目

    预设和技能只改配置；MCP 和插件会在本机跑代码，先看权限。

    anbot search <关键词>

  3. 3装进本机

    配置和文件落在本地，不经过服务器；卸掉就是删掉那份配置。

    anbot install <id>

关于 Anbot

Anbot 是一个开源的多 Agent 工作台：一支持久在线的 Bot 团队，在你的真实工作区里干活。主 Bot 拆任务，专业 Bot 接活，团队共享记忆、群聊和同一个工作区。

这份目录有 27 条配置（15 个预设、2 个技能、6 个MCP、4 个插件），都读同一份 index.json；装进你自己的 Anbot，数据和执行留在本机。

Anbot 是什么？

Anbot 是一个开源的多 Agent 工作台：一支持久在线的 Bot 团队，在你的真实工作区里干活。主 Bot 拆任务，专业 Bot 接活，团队共享记忆、群聊和同一个工作区。

这个市场里有什么？

27 条配置，15 个预设、2 个技能、6 个MCP、4 个插件；都读同一份 index.json，在本机安装。

数据会上传吗？

不会。团队、聊天、记忆、凭据和执行记录留在本机；模型请求只发给你配置的模型服务商。

Anbot 开源吗？

是，Apache 2.0。应用和插件代码开源；预设、技能和 MCP/插件索引可读、可换。

和 Grok Bot、大厂 Agent 有什么区别？

Grok Bot 是付费云端的 Bot 团队；Anbot 开源、跑在你的真实工作区里，你可以接管。大厂 Agent 的运行时、模型和扩展面归厂商；Anbot 把代码、模型选择和扩展面保持开放。
